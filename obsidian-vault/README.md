# alibot — Obsidian vault

Это не документация, а **живой срез реальных данных** сервиса ремонта (заказы, мастера,
пользователи) в виде markdown-заметок со свойствами (frontmatter) — чтобы смотреть, искать
и фильтровать их прямо в Obsidian, не заходя в БД и не гоняя curl вручную.

## Как открыть

`Файл → Открыть папку как vault…` → выбрать эту папку (`alibot/obsidian-vault`), не корень
проекта — иначе Obsidian попытается проиндексировать и Java-исходники.

## Структура

- `Заказы/` — по одной заметке на заказ (`Order-<номер>.md`), синхронизируется скриптом
- `Мастера/` — по одной заметке на мастера (`<Имя> (<id8>).md`), синхронизируется скриптом
- `Пользователи/` — пользователи системы (роли SUPERADMIN/ADMIN/MASTER). API отдаёт список
  пользователей только SUPERADMIN-токеном, а не по внутреннему API-ключу сервиса, поэтому
  сюда заметки добавляются вручную по мере надобности, а не скриптом
- `Обзор.md` — точка входа: ссылки на разделы

## Свойства (frontmatter) заказа

| Свойство | Смысл |
|---|---|
| `status` | текущий статус (NEW, ASSIGNED, ACCEPTED, ... PAID, CANCELLED и т.д.) |
| `master` | wiki-ссылка на заметку мастера, если назначен |
| `final_price` / `amount_paid` / `amount_due` | финансовые поля как в ТЗ п.13 |
| `visit_date`, `time_from`, `time_to` | дата и слот визита |

В самом Obsidian: клик по любому свойству в панели **Properties** справа даёт быстрый
фильтр/поиск по всем заметкам с таким же значением (например все заказы `status: WAITING_PART`).

## Обновление данных

Данные не пишутся сюда руками — синхронизируются из работающего backend через тот же REST
API, которым пользуется Mini App (`GET /api/v1/orders`, `GET /api/v1/masters`):

```powershell
./scripts/sync-obsidian.ps1
```

По умолчанию скрипт стучится в `http://localhost:8099` с ключом `dev-api-key` (dev-профиль).
Для боевого backend:

```powershell
./scripts/sync-obsidian.ps1 -BaseUrl "http://localhost:8080" -ApiKey $env:INTERNAL_API_KEY
```

Скрипт идемпотентен — перезаписывает заметки по id/номеру заказа, можно гонять на
расписании (Планировщик заданий Windows) для почти-живой синхронизации. Изменения в заметках
Obsidian **не** попадают обратно в систему — это read-only витрина, не форма ввода.

## Зависимости

Ничего, кроме самого Obsidian, не требуется. Заметки мастеров содержат необязательный блок
[Dataview](obsidian://show-plugin?id=dataview) с запросом "заказы этого мастера" — если
плагин не установлен, Obsidian просто покажет текст блока кода как есть, ничего не сломается;
связь заказ↔мастер и без Dataview видна через панель **Backlinks**.
