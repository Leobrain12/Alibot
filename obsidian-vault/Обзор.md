## Быстрые фильтры (Dataview, опционально)

``````dataview
TABLE status as "Статус", customer as "Клиент", master as "Мастер", visit_date as "Дата"
FROM "Заказы"
WHERE type = "order"
SORT visit_date DESC
``````

``````dataview
TABLE status as "Статус", active as "Активен"
FROM "Мастера"
WHERE type = "master"
``````

Без плагина Dataview эти блоки просто показывают текст запроса — не мешает. Без него ищите
через **Properties** (правая панель) или обычный поиск `status:WAITING_PART` и т.п.
