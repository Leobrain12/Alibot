# Пользователи

В отличие от `Заказы/` и `Мастера/`, эта папка **не** синхронизируется скриптом: список
пользователей (`GET /api/v1/users`) доступен только по правам SUPERADMIN, а
`sync-obsidian.ps1` ходит по внутреннему API-ключу сервиса (роль ADMIN, см.
`SystemActorBootstrap`) — у него на это прав нет. Добавляйте сюда заметки вручную по мере
создания реальных пользователей, по образцу [[Superadmin]].
